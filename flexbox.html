Display

Display posiada 2 wartości pozwalające na utworzenie flexboxa.

.container { display: flex; }

flex: Zachowuje się jak element blokowy, zajmuje całą szerokość strony, elementy ustawiają się pod nim.

Flex-direction określa kierunek głównej osi flexboxa.

Zapytania o media

Zapytania o media pozwalają na tworzenie responsywnych stron, które dostosowują się do różnych rozmiarów ekranu.

@media (max-width: 768px) { .element { width: 100%; } }

max-width: Stosuje style, gdy szerokość ekranu jest mniejsza lub równa podanej wartości.

Ekran > 768px: Czerwony | Ekran ≤ 768px: Zielony
@media (min-width: 769px) { .element { width: 80%; } }

min-width: Stosuje style, gdy szerokość ekranu jest większa lub równa podanej wartości.

Ekran < 769px: Niebieski | Ekran ≥ 769px: Purpurowy
@media (min-width: 768px) and (max-width: 1024px) { .element { width: 750px; } }

Zakresowa media query: Stosuje style w określonym zakresie szerokości ekranu.

Ekran < 768px: Czerwony | Ekran 768-1024px: Zielony | Ekran > 1024px: Niebieski
